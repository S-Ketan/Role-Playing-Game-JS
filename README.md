# Dragon Repeller

Dragon Repeller is a simple RPG game built with HTML, CSS, and JavaScript. The objective of the game is to defeat the dragon that is preventing people from leaving the town. Players can explore different locations, fight monsters, and upgrade their weapons.

## Game Features

- Explore different locations: town square, store, cave, and more.
- Fight various monsters: slime, fanged beast, and dragon.
- Upgrade your weapons and buy health.
- Interactive buttons and dynamic text updates.
- Basic inventory system.

## How to Play

1. Clone the repository:
    ```sh
    git clone https://github.com/yourusername/dragon-repeller.git
    ```
2. Open `index.html` in your web browser.
3. Use the buttons to navigate through different locations and interact with the game.
4. Defeat the dragon to win the game!

## File Structure

- `index.html`: The main HTML file that contains the game layout.
- `style.css`: The CSS file for styling the game.
- `script.js`: The JavaScript file that contains the game logic.
